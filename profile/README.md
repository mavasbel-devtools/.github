### 🔒 Private

| Area | What it covers |
|:---|:---|
| **OpenCode provider plugins** | Sign-in, model discovery, and request handling for additional model providers |
| **OpenCode session tooling** | Session ID visibility, moving sessions across directories, and a terminal session browser |
| **Plugin maintenance** | Auditable, re-runnable patch sets for installed OpenCode plugins |
| **Local LLM router** | One loopback endpoint that speaks the Anthropic, OpenAI, and Gemini API formats |
| **MCP servers** | Model Context Protocol servers for messaging platforms |
